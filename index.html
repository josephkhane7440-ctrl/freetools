Frequently Asked Questions

How can I compress an image online?

Select one or more JPG, PNG or WebP images, choose your target file size and click "Compress Images". You can then download your compressed images as a ZIP file.

Is ToolForge image compression free?

Yes. ToolForge provides this image compression tool free of charge.

Can I compress multiple images at once?

Yes. You can select multiple JPG, PNG and WebP images and process them together.

Does ToolForge upload my images?

The image compression process is designed to run directly inside your web browser using JavaScript rather than requiring your images to be uploaded to a ToolForge server.

What image formats are supported?

ToolForge currently supports JPG, PNG and WebP image files.

Can I download all compressed images together?

Yes. After compression, the images can be downloaded together as a ZIP archive.
